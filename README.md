# CS-650: Software Development Lifecycle

## About This Repository

This repository contains coursework, activities, and projects completed for **CS-650** as part of my Master of Science in Software Engineering program at Southern New Hampshire University (SNHU).

The course focused on applying software engineering practices throughout the software development lifecycle, with particular attention to secure development, testing, automation, continuous integration, deployment, monitoring, and software quality.

Throughout the course, I worked with practical development scenarios that required me to analyze software requirements, implement and test solutions, troubleshoot technical issues, and apply industry-standard development practices.

## Project One

Project One required the application of software engineering concepts to a larger development scenario. The project involved evaluating application requirements, implementing and testing functionality, addressing security and quality considerations, and documenting the development process.

The repository contains both the written Project One submission and the supporting project files.

## Project Two

Project Two expanded on the concepts developed throughout the course and required the integration of development, testing, security, deployment, and quality-management practices.

The project demonstrates the importance of treating software quality as an ongoing process throughout the development lifecycle rather than as a final testing activity.

Supporting source files and the final written Project Two submission are included in this repository.

## Testing and Quality Assurance

A major focus of this coursework was understanding how testing fits into the broader software development lifecycle. Activities included automated testing, debugging, security testing, and evaluating application behavior under different conditions.

The course reinforced the importance of selecting testing strategies based on application risk, business requirements, and the potential impact of software failures.

## Continuous Integration and Automation

The repository also reflects experience working with automated development workflows. These activities demonstrated how source control, automated testing, and continuous integration can work together to identify problems earlier in development and improve software reliability.

## Security

Security was incorporated throughout the development process. Coursework included securing API routes, protecting authentication information, managing authorization, identifying vulnerabilities, and considering security requirements during application design and testing.
